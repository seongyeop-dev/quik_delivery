# 01. 프로젝트 요약

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 프로젝트명 | Quik Delivery |
| 한 줄 소개 | Unity 기반 배송 업무·수익·월별 정산 관리 Android 앱 |
| 구분 | 개인 프로젝트 |
| 기간 | 2026.05 ~ 2026.07 |
| 플랫폼 | Android |
| 주요 기술 | Unity, C#, uGUI, TextMeshPro, JSON, NativeFilePicker |
| 저장 방식 | `Application.persistentDataPath` 기반 로컬 JSON |

## 배경

실제 배송 업무에서는 배송 1건의 수입만 기록하는 것으로 끝나지 않습니다. 근무 시작·종료, 기본요금과 추가요금, 회사입금, 데이터사용료, 전기비, 통행료, 기타 차감액을 함께 관리해야 월별 실수령액을 확인할 수 있습니다.

기존 수기 기록을 반복해서 계산하는 불편을 줄이고, 모바일에서 바로 기록·조회·백업할 수 있는 개인 업무 도구를 만드는 것을 목표로 했습니다.

## 해결하려는 문제

1. 배송기록과 근무시간이 분리되어 월간 업무 흐름을 한눈에 보기 어렵다.
2. 수입과 여러 비용 항목을 매번 직접 계산해야 한다.
3. 배송이 없는 날짜에는 일일 고정비가 누락되어 월별 데이터가 달라진다.
4. 기기 변경이나 앱 업데이트 시 기존 데이터를 안전하게 보존해야 한다.
5. 실제 사용 데이터는 공개 저장소와 포트폴리오에서 분리해야 한다.

## 목표

- 기록 생성·수정·삭제와 입력 보정
- 수입·비용·실수령액 자동 계산
- 근무시간과 배송 데이터 통합 조회
- 통계·달력·월별 정산 화면 구성
- 누락된 고정비만 추가하는 데이터 보정
- JSON 백업·내보내기·불러오기
- 기존 앱 데이터를 유지하는 업데이트 구조 준비

## 구현 범위

### 구현 완료

- 배송·근무 기록 관리
- 홈·기록·통계·달력·정산 화면
- 연도별 월 카드 12개
- 일일 고정비 누락 보정과 중복 방지
- 전체 데이터 백업 및 Android 파일 선택 복원
- Android APK 빌드 산출물

### 최종 검증 필요

- 기존 앱 위 최종 APK 업데이트 설치
- 업데이트 전후 레코드 유지와 중복 미생성
- Android 실기기 파일 내보내기·복원 회귀 테스트

## 프로젝트 포지셔닝

Quik Delivery는 대규모 산업 관제 프로젝트가 아니라, **실제 개인 업무에서 발견한 데이터 불일치 문제를 Unity 모바일 앱으로 해결하고 지속적으로 개선한 실사용형 개인 프로젝트**입니다.
