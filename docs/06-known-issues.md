# 현재 제한과 개선 방향

## 현재 제한

- 단일 기기 JSON 저장을 사용하며 서버·클라우드 동기화가 없습니다.
- 저장 파일 암호화와 사용자 인증이 적용되지 않았습니다.
- Android 제조사와 버전에 따라 파일 선택·다운로드 경로가 달라질 수 있습니다.
- 위치 자동 입력은 권한과 기기 위치 서비스 상태에 영향을 받습니다.
- 기록 목록은 화면 성능을 위해 최대 표시 건수를 제한합니다.
- 앱 스토어 배포, 서명 자동화와 업데이트 배포 체계는 현재 범위에 포함하지 않습니다.
- 자동화된 테스트보다 실사용 시나리오 기반 수동 검증을 중심으로 확인했습니다.

## 개선 방향

- 로컬 데이터 암호화
- 클라우드 백업과 기기 간 동기화
- 계산 로직과 Repository 단위 테스트
- CSV·PDF 정산 내보내기
- Android 저장소 접근 방식의 버전별 분기 강화
- 대량 기록 가상화 목록과 검색
- 사용자별 고정비·계산 규칙 설정 화면
