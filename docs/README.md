## 표현 기준

- 실제 코드와 Scene에서 확인되는 기능만 작성합니다.
- 서버·클라우드·외부 DB 기능을 추가하지 않습니다.
- APK 생성과 기존 앱 업데이트 검증을 구분합니다.
- 개인 데이터가 담긴 백업·기록 파일은 공개하지 않습니다.
- 부가세 화면은 입력 데이터 조회·정리 기능이며 공식 세무 계산 서비스로 표현하지 않습니다.
