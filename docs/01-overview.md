# 프로젝트 개요

## 배경

배달 업무 기록은 배송 건수만으로 끝나지 않습니다. 근무시간, 기본 요금과 추가 요금, 회사 입금·데이터 이용료·통행료·충전비 등의 비용, 부가세와 월별 정산을 함께 관리해야 합니다.

기존 메모나 스프레드시트 방식에서 발생하는 반복 입력과 누락을 줄이기 위해 Android에서 직접 사용하는 Unity 기반 개인 앱으로 구성했습니다.

## 목표

- 배송 기록 등록·수정·삭제
- 수입·비용·부가세·실수령 자동 계산
- 근무 시작·종료와 수동 시간 보정
- 기간별 통계와 월간 캘린더 분석
- 연도별 12개월 정산
- 배송이 없는 날짜의 일일 고정비 누락 방지
- JSON 백업·복원과 다운로드 폴더 내보내기
- Android 실기기 설치·사용

## 구현 범위

| 영역 | 구현 내용 |
|---|---|
| Home | 오늘·이번 달·전체 요약, 근무 상태, 최근 기록 |
| Delivery | 배송 기록 입력·수정·삭제와 계산 결과 |
| Records | 오늘·주간·월간·부가세 기록 필터 |
| Stats | 오늘·주간·월간·연간·전체·직접 기간과 금액 필터 |
| Calendar | 일별 근무시간·건수·수입·비용·부가세, 주간 차트 |
| Settlement | 연도 선택, 1~12월 월별 요약 카드 |
| Backup | 전체 백업, 다운로드 내보내기, 파일 선택 복원 |
| Settings | 위치 자동 입력, 글자 크기, 삭제 확인 설정 |

## 프로젝트 성격

개인 사용 흐름을 해결하기 위해 요구사항 정의, 데이터 모델링, 계산 로직, Android 파일 접근, UI 구성과 실기기 검증까지 단독으로 진행한 프로젝트입니다.
