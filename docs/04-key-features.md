# 04. 핵심 기능

## 1. 배송 기록 등록과 수정

입력 항목은 날짜, 시간, 출발지, 도착지, 기본요금, 부가세 포함 요금, 추가요금, 회사입금, 데이터사용료, 기타 차감, 전기비, 통행료, 메모로 구성됩니다.

입력값 변경 시 `RevenueCalculator`로 총수입·총비용·부가세·실수령액을 즉시 표시합니다. 수정 모드에서는 기존 ID와 연결 정보를 유지한 채 입력 UI에 값을 다시 바인딩합니다.

## 2. 근무 상태 관리

- 근무 시작과 종료
- 현재 근무 상태 표시
- 오늘·이번 달 근무시간 집계
- 과거 날짜의 시작·종료시간 수정
- 잘못된 시간 입력 형식 보정

## 3. 기록 목록과 부가세 조회

일반 기록 화면은 오늘·최근 7일·월간·특정 날짜 기준으로 목록을 표시합니다. 수정과 삭제 버튼은 레코드 ID로 동작합니다.

부가세 화면은 선택 월의 `BaseFeeVatSource`와 `VatAmount` 기록만 모아 월 합계와 행 단위 값을 표시합니다. 이 영역은 런타임 UI 생성 방식을 유지합니다.

## 4. 통계와 필터

- 오늘·주간·월간·연간·전체 기간
- 사용자 지정 시작일·종료일
- 최소·최대 금액 필터
- 총수입·총비용·실수령액 및 세부 항목 선택
- 오늘·월 근무시간 표시

## 5. 달력 분석

- 이전·다음 월 이동
- 날짜별 배송 건수와 금액 요약
- 선택일 상세 요약
- 월간 근무시간
- 주 단위 막대 그래프
- 통계 화면에서 선택한 분석 항목을 달력으로 전달

## 6. 연도별 월 정산

- 좌우 화살표로 연도 이동
- 1월~12월 카드 항상 표시
- 2열 Grid, 모바일 세로 스크롤
- 월별 배송 건수, 총수입, 항목별 비용, 지출합계, 실수령액
- 데이터 없는 월은 0건·0원
- 미래 연도로 이동해도 미래 고정비는 생성하지 않음

## 7. 일일 고정비 누락 보정

운영 기준 시작일 이후 매 날짜를 검사하여 고정비가 없는 날에만 `IsDailyFixedExpense=true` 레코드를 추가합니다.

- 전체 기록 1회 로드
- 기존 고정비 날짜 `HashSet` 수집
- 누락 날짜만 신규 레코드 추가
- 추가가 있을 때만 1회 저장
- 재진입 방지
- 앱 시작·자정·포커스 복귀·백업 복원 시 확인

## 8. 백업과 복원

배송기록과 근무기록을 하나의 `FullBackupData`로 저장합니다.

- 전체 백업 생성
- 내부 최신 백업 검색
- Android Download 내보내기
- Android 파일 선택 복원
- Editor/비 Android 환경 최신 백업 복원
- 복원 직후 누락 고정비 재검사
