# 02. 역할과 기여

## 프로젝트 구분

개인 프로젝트로 기획, 데이터 모델, UI, 저장 구조, Android 빌드와 개선 작업을 직접 수행했습니다.

## 담당 범위

### 기획과 정보 구조

- 배송 등록에 필요한 날짜·시간·주소·금액 항목 정의
- 홈·기록·통계·달력·정산의 화면 흐름 설계
- 근무 상태와 배송기록의 조회 기준 정리
- 수입·비용·부가세·실수령액 표시 규칙 정의

### 데이터 구조

- `DeliveryRecord`, `WorkSession`, `AppSettings` 모델 설계
- 고유 ID 기반 수정·삭제 구조
- Repository와 JSON 저장 계층 분리
- 월별 Summary와 날짜 범위 조회 API 구현

### UI 구현

- uGUI와 TextMeshPro 기반 모바일 세로 화면
- 입력 즉시 계산 결과 갱신
- 기록 리스트와 부가세 테이블 런타임 생성
- 달력 셀과 주간 차트 런타임 생성
- 정산 화면은 Edit Mode 12개월 2열 Grid로 구성

### 데이터 안정화

- 배송 0건 날짜의 일일 고정비 누락 원인 분석
- 기존 데이터 변경 없이 누락 날짜만 보정
- 앱 시작·자정·복귀·백업 복원 진입점 통합
- 같은 날짜 중복 생성을 막는 `HashSet`과 재진입 플래그 적용

### Android 연동

- 위치 권한 요청과 현재 위치 1회 조회
- Android Geocoder 기반 주소 변환
- Download 폴더 백업 내보내기
- NativeFilePicker 기반 백업 JSON 선택·복원
- APK 빌드와 기존 앱 업데이트 준비

## 기여를 설명하는 핵심 문장

> 단순한 UI 제작보다 배송 데이터의 생성·계산·저장·조회·복원 전체 흐름을 설계했고, 실사용 중 발견한 누락 데이터 문제를 기존 기록을 보존하는 보정 로직으로 해결했습니다.
