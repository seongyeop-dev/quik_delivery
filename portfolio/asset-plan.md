# Quik Delivery 이미지 계획

실제 주소·업무 메모·수입·근무시간이 포함된 화면은 그대로 공개하지 않습니다. 포트폴리오 이미지는 **테스트 데이터로 재촬영**하는 것을 원칙으로 합니다.

| 우선순위 | 추천 파일명 | 화면 | 보여줄 내용 | 개인정보 처리 |
|---:|---|---|---|---|
| 1 | `overview/quik-delivery-overview.png` | 홈 | 근무 상태, 오늘·월간 요약, 하단 내비 | 전부 테스트 값 |
| 2 | `features/delivery-input.png` | 배송 등록 | 입력 항목과 실시간 계산 | 가상 주소·금액 |
| 3 | `features/record-list.png` | 기록 | 날짜 그룹, 수정·삭제 | 가상 기록 |
| 4 | `features/stats-filter.png` | 통계 | 기간·금액 필터와 항목 분석 | 가상 합계 |
| 5 | `features/calendar-view.png` | 달력 | 월간 셀, 선택일, 주간 차트 | 가상 데이터 |
| 6 | `settlement/monthly-settlement.png` | 정산 | 12개월 2열 카드와 연도 이동 | 가상 금액 |
| 7 | `backup/backup-toggle.png` | 정산 백업 | 접힌 상태와 열린 상태 | 파일명도 테스트 |
| 8 | `settlement/fixed-expense-flow.png` | 문서용 도식 | 누락 날짜 보정 흐름 | 실제 금액 미표시 |

## README 대표 이미지

`overview/quik-delivery-overview.png`와 `settlement/monthly-settlement.png` 2장을 우선 사용합니다.

## Portfolio_Hub 카드 이미지

월별 정산 2열 카드 화면은 프로젝트의 데이터 관리 특징을 한 장에서 보여주므로 허브 대표 이미지에 적합합니다.

## 촬영 기준

- 상태바와 개인 계정 정보 제거
- 주소는 `테스트 출발지`, `테스트 도착지`
- 금액은 작은 예시 숫자로 통일
- 실제 백업 파일명 사용 금지
- 동일 해상도와 여백 유지
