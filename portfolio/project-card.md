# Quik Delivery — Project Card

## 한 줄 소개

Unity 기반 배송 업무·수익·월별 정산 관리 Android 앱

## 프로젝트 정보

- **구분:** 개인 프로젝트
- **기간:** 2026.05 ~ 2026.07
- **기술:** Unity, C#, uGUI, TextMeshPro, JSON, NativeFilePicker
- **플랫폼:** Android

## 해결한 문제

배송이 없는 날짜에는 일일 고정비가 생성되지 않아 월별 비용이 누락되는 문제를 발견했습니다. 기존 배송기록을 변경하지 않고 기준일부터 오늘까지 누락 날짜만 추가하고, 앱 실행·자정·복귀·백업 복원 시에도 중복 없이 유지하는 보정 로직을 구현했습니다.

## 핵심 구현

- 배송·근무 기록 CRUD와 JSON 영속성
- 수입·비용·부가세·실수령액 자동 계산
- 통계·달력·월별 정산 화면
- 12개월 2열 Grid와 연도 이동
- 전체 백업·Download 내보내기·파일 선택 복원
- 기존 데이터 보존형 일일 고정비 소급 보정

## 대표 성과

- 실사용 데이터에서 발생한 정합성 문제를 발견하고 구조적으로 해결
- 고정비를 배송 건수에서 제외하면서 비용에는 포함하는 집계 규칙 분리
- 정산만 Edit Mode로 전환하고 다른 런타임 UI 동작은 보존
- APK 빌드 산출물 생성

## 정확한 상태

주요 기능과 APK 빌드는 완료했습니다. 기존 앱 위 최종 업데이트 설치 후 데이터 유지와 중복 미생성은 최종 검증 항목입니다.
